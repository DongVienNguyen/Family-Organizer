# Tiến độ PC

Chưa chạy trên PC tại thời điểm bàn giao. Không chuyển kết quả Cloud thành kết quả PC.

Sau mỗi nhóm sửa, thêm: ngày, SHA/checkpoint, task ID, file đã đổi, thao tác thực
tế, lệnh/exit code, lỗi còn lại, tests chưa chạy và bước tiếp theo. Dùng dữ liệu
synthetic; không ghi credentials hoặc dữ liệu gia đình thật vào tài liệu.
