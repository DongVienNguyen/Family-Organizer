# F08-d — raw quality agreement and trusted source policy

This slice supplies pure report validation and a read-only Git policy reader for
the future full collector. It neither extracts an archive nor enables publication.
A serialized operator receipt is never authority for source or required suites.

The source reader retains checked HEAD, own repository origin, explicit main
ancestry and package version from F08-b. It derives every tracked unit suite and
production coverage source from the target Git tree, checks ordinary blob modes,
and hashes exact current Windows checkout text bytes for source, lockfile and
measured coverage policy. It refuses symlink/submodule sources, nested or unsupported
attribute policy, ignore pragmas, excessive inventory/bytes/time and native errors.
Changing text attributes requires reviewed conversion support. Cloud compatibility
matched all118 actual Windows source hashes; this is not trusted-main adapter proof.

The raw quality validator requires exact source/run/runtime/lock/Windows2022 identity,
all eight quality steps and their actual native exits, nonempty complete JSON tests,
mandatory suites, per-assertion pass/error-free status, and matching suite receipts.
Its bounded JUnit vocabulary parser rejects DTD/entities, malformed hierarchy,
duplicate attributes, unexpected roots and hidden testcase structures. JUnit must
match each suite and the exact multiset of ancestor/title assertion names. Legitimate
parameterized names may repeat; their multiplicity must agree in both raw formats.
Root/suite counters and all failed/skipped markers are checked independently.

Availability REDs46+17 are new contract availability, not application defects.
Actual synthetic Windows report inspection corrected assumptions about the OS label,
reporter name separators and repeated parameterized names. Two new-code XML hierarchy
REDs and two counter REDs now pass; two critical omission REDs enforce the new suites.
All old assertions remain. Pure target216/3 passed; full source/review/native execution
remain required. No full report/candidate trust, Server2019 or publication claim.

The remaining collector must authenticate archive bytes in process, extract safely,
read bounded ordinary files, bind source-derived policy, verify native/production,
audit, raw coverage/LCOV, browser, package/license and service/update/cleanup evidence,
and rehash the exact inner ZIP. Those are mandatory gates, not replaced by this policy.
