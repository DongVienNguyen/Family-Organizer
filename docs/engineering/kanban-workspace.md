# Actor-owned Kanban workspace (P09-c)

The Task shell adds Kanban beside List, Matrix and the retained legacy Kanban.
The new workspace lists current owned supported saved boards, chooses an explicit
timezone and consumes validated canonical/grouped pages. Cards use the existing
shared canonical Task drawer and authorization cache; projections never become
another full-cache authority or draft store. Runtime startup/default schemas and
the package's generated6/9/1 fixtures are unchanged.

The transient controller owns aborts and generations. New selections clear old
facts immediately, late results cannot replace a newer view, and load-more is
singleflight. Any failed page append/read clears the projection while retaining
only typed HTTP status, not exception text. Explicit refresh starts a fresh read;
authority clear forgets its selection, and dispose aborts and stops notifications.
Controller and saved-view metadata are bound to the current TaskProvider API,
which changes with the session key. Pending/failed/offline authorization hides
old rows synchronously; opening rechecks the current full authorized Task cache.

Only a view still present in current controller-owned rows is selected. Actual
Chromium diagnostics found that changing an owned Kanban view into a List cleared
cards but retained its old ID, placeholder and dead reload control. One Important
review correction makes selection depend on current membership. The regression
keeps both expected empty-choice text and no-dead-reload assertions.
