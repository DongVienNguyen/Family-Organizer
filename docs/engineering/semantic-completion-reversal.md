No DDL, new reward collection or dependency is introduced.

Session-authenticated POST `/api/productivity/tasks/:id/reopen` checks current SQL actor and Task/list authority before cache replay and inside the transaction. A completed Task returns to Todo, clears completed/submitted/proof metadata and reverses its linked award exactly once. Repeating a committed UUID acknowledges the same response; a fresh request on the reopened Task is a no-op. Pending Review and Won't Do cannot be reopened through this command.
