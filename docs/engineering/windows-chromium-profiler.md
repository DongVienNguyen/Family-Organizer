The patch is a narrowly scoped upstream-supported mitigation, not a claim that a local dump proved that stack.

`browser-launch-policy.mjs` adds that single flag only to Windows Chromium. It retains the exact pinned executable and all browser behavior assertions. Firefox/WebKit and other platforms keep their original options. No dependency, rendering, video, trace, PWA/service-worker policy, worker count, retry or timeout change is made. Browser crashes still fail the suite. Driver records retain only a boolean when the exact flag is observed; launch commands/private arguments remain redacted.

Native touch now inherits the ordinary Chromium project's explicit executable and launch options, while retaining mobile/touch/viewport/reduced-motion settings. This makes the configured executable match the path whose hash its runtime report records. Historical receipts are preserved; they are not rewritten as evidence of this new explicit launch binding.

Regression coverage checks the platform/engine matrix, exact pinned paths, ordinary/Productivity/touch agreement, unchanged diagnostic/assertion settings, redaction and exact-flag matching. The new launch suite is mandatory. New exact-HEAD Windows evidence is required before merge. Server2019 acceptance, release/tag and VPS operations remain not run.
